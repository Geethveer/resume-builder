# Contributing

- Use feature branches and pull requests. Run `python -m pytest -q tests/` before opening a PR.
- Never commit actual applicant resumes, personal information, H-1B workbooks, immigration documents, generated applications, API credentials, or secret keys.
- All sample profiles and employers must be fictional.
- Keep screening status evidence-driven. A missing work authorization or sponsorship statement is not proof of eligibility.
- Do not present an estimated ATS-alignment score as an employer's actual ATS grade.
- The development server is local-only and must not be deployed publicly without authentication, tenant isolation, upload safety and encryption.
